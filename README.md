# Dead Frontier: Fortress

iPhone-first browser zombie survival prototype.

## Features
- Top-down open world
- Mobile virtual joystick
- Shooting and multiple weapons
- Zombie waves and brute zombies
- Scavenging
- Inventory
- Wood/metal resources
- Build/remove fortifications
- Starter fortress
- Day/night cycle
- Local save/load
- PWA-ready files for HTTPS hosting

## iPhone
Host these files on GitHub Pages or another HTTPS static host, open the site in Safari, then use Share -> Add to Home Screen.

This is a prototype foundation for the larger game.
